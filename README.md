# Feather by Simple Labs — website

Static GitHub Pages website for Feather.

## Before publishing
1. Replace the placeholder Chrome Web Store URL in `index.html` with the published Feather listing URL.
2. Add a real support contact (for example, a public GitHub Issues URL or dedicated email) to `support.html` and `privacy.html`.
3. Review the privacy policy against the exact release being published.
4. Add screenshots to `assets/screenshots/` and update `index.html` if desired.

## Pages
- `index.html` — landing page
- `support.html` — support and FAQ
- `privacy.html` — privacy policy
